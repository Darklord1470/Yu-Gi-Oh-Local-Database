# Yu-Gi-Oh-Local-Database
A local Yu-Gi-Oh Database to browse and search all the cards in the game. You can fetch new cards from the official website, and search cards by name or using additional parameters. 

# How to run
1) Create a python virtual environment (es. .venv or .conda)
2) Clone or download the repository
3) Enter the repository folder
4) Run "pip install -r requirements.txt" to fetch the required packages
5) Run "python yugioh_MAIN.py" to execute the main script
